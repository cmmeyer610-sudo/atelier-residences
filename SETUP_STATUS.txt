2. In GitHub Desktop, clone cmmeyer610-sudo/atelier-residences.
3. Copy the CONTENTS of the extracted atelier-residences folder into the
   cloned repository folder. Allow the README to be replaced.
4. Confirm package.json, netlify.toml, public/, runtime-assets/ and scripts/

5. Commit with message: Publish complete Atelier R3 viewer and runtime assets.
6. Push origin on main.

All four are standard ZIPs, each below 100 MB. Together they contain the
complete project. No special multipart archive program is required.

Optional Windows PowerShell command, run in the folder with the four ZIPs:
  Get-ChildItem .\Atelier_R3_GitHub_*_of_04.zip | ForEach-Object { Expand-Archive -LiteralPath $_.FullName -DestinationPath .\Atelier_R3_GitHub -Force }

Upload the extracted files to GitHub, not the ZIP files themselves.
The project contains over 700 files; GitHub Desktop avoids browser upload

required for this prepared package.

NETLIFY AFTER THE GITHUB PUSH
Connect the intended viewer project to the repository and use:
  Production branch: main
  Base directory: leave blank (repository root)
  Build command: npm run build
  Publish directory: dist
  Node version: 22 (already set in netlify.toml)

Netlify supplies COMMIT_REF during its Git build. The build checks every
asset and pins model/image/HDR URLs to that exact GitHub commit.
Do not set ASSET_REF to the initial README-only commit.
Do not publish the repository root or public/ directly.
The Netlify interface is approximately 3.7 MB; 530.8 MB of runtime assets
remain in GitHub and are loaded as needed.
